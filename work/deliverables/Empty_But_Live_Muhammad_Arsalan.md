## 2. Part 1: Three Roads — Choosing the Stack with AI

### The Four Constraints
1. **Free Only:** Must cost $0.00 to build, deploy, and host indefinitely.
2. **Honest Skill Level:** Intermediate in Python, ML, and algorithms; learning modern web deployment; must be able to maintain and debug every line of code without getting trapped in build tooling.
3. **What It Needs to Do:** Host a 4-page site (`Home`, `Work`, `About`, `Contact`) with structured three-beat case studies, visual charts, and a Calendly/Email CTA.
4. **How My Work Must Be Shown:** As an Applied AI & ML candidate, my proof consists of:
   - Real SVG pipeline benchmark charts and precision distributions.
   - Clear UI screen captures of Streamlit computer vision apps.
   - Code repository links and Google Colab badges.
   - High-contrast, legible technical prose.
5. **Dynamic at Launch?** **No.** A contact mailto link and embedded Calendly scheduler provide all necessary interaction without needing a custom database or server backend.

---

### The Three Options Evaluated

| Road | Stack & Host | Build Approach | How It Shows ML Work | The Real Trade-Off |
|---|---|---|---|---|
| **Road 1: No-Code (Simplest)** | Carrd / Framer on Free Tier | Visual drag-and-drop builder; no terminal or code required. | Good for basic visual galleries, but awkward for linking code repos, hosting SVG charts, or proving technical engineering fluency. | Trapped in a proprietary platform; free tiers often add branded watermarks; doesn't demonstrate code ownership. |
| **Road 2: Plain Code with AI (The Sweet Spot — CHOSEN)** | Semantic HTML5 + Modern CSS on **GitHub Pages & Netlify** | Plain HTML/CSS files built alongside AI; zero build dependencies; hosted straight from repo. | **Ideal.** Clean, fast, perfectly renders custom SVG diagrams, embeds Colab badges, and the repo itself serves as proof of developer competence. | Requires writing and editing markup directly, but has zero maintenance debt—nothing breaks in 6 months. |
| **Road 3: Framework (Most Powerful)** | Next.js / Astro / React on Vercel | Full JavaScript framework with npm packages, components, and automated build pipelines. | Highly customizable, but massive overkill for a static 4-page portfolio. | High maintenance overhead; package vulnerabilities and build failures waste time that should be spent refining ML case studies. |

---

### The Decision & Rationale

> **Chosen Stack:** **Plain Semantic HTML5 & Modern CSS on GitHub Pages (with Netlify Drop compatibility).**
>
> **Why I picked this road:**  
> "As an Applied AI & Machine Learning engineer, the code repository is part of my resume. Using plain HTML5 and CSS with zero heavy JavaScript frameworks gives me complete control over typography (`Space Grotesk` + `Inter`), guarantees instant page load speeds, perfectly displays SVG pipeline charts, and eliminates build errors entirely.  
> 
> **Can I maintain this?** Yes, 100%. There are no `node_modules`, no webpack bundlers, and no breaking dependency updates. Ten years from now, these HTML files will still render identically in any browser on earth."
